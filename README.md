# Forever Fishing

Portable Windows releases and in-app updates.

**[Download the latest release](https://github.com/Ferox13/ff-releases/releases/latest)**

Download the Windows x64 ZIP, extract the complete folder and run `ForeverFishing.exe`.
Keep `_internal` beside the executable. No Python installation or GitHub token is required.

Each release includes the Windows ZIP, `release-manifest.json` for the updater and `SHA256SUMS`
for download verification. Source code and development reports are maintained separately.

Use **Update** in the app for future versions. Builds before 1.0 need one manual download
to switch to public updates. Settings and calibration remain in `%LOCALAPPDATA%\ForeverFishing`.

The app starts in Simulation. Check audio calibration, casting and Interact keys, auto loot
and chat logging before using automatic fishing. Press F8 or leave the game window to stop.

Windows 10/11 x64 is required. Releases are unsigned; actual hardware and in-game behavior
require local testing. See the bundled README, license and third-party notices.
